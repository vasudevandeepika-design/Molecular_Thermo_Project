# Molecular Thermo Project

This repository contains Python implementations developed for computational studies in molecular thermodynamics and statistical mechanics.

## Projects

### 1. 2D Ising Model — Monte Carlo Simulation

`ising_MC.py`

A Python-based Monte Carlo simulation of the two-dimensional Ising model using Glauber/Metropolis dynamics and periodic boundary conditions.

The simulation studies the effect of:

- Interaction strength
- External magnetic field
- Lattice size

on thermodynamic and statistical properties such as:

- Magnetization
- Magnetic susceptibility
- Specific heat

### 2. Random Number Generation

`random_number_generation.py`

Python implementation of random number generation methods based on binary sequences and shift-register techniques, followed by conversion of the generated binary sequence into uniformly distributed random numbers.
